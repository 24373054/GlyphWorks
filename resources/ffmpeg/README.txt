内置 FFmpeg 二进制说明

本目录随安装包携带以下文件，供字符工坊 GlyphWorks 在本地解码视频与编码导出：

- ffmpeg.exe
- ffprobe.exe
- LICENSE.txt（FFmpeg LGPL 许可文本，构建包自带）

来源：gyan.dev 提供的 Windows 静态构建
版本：ffmpeg-2025-12-04-git-d6458f6a8b-essentials_build
下载页：https://www.gyan.dev/ffmpeg/builds/

该构建为 LGPL 许可。根据 LGPL 要求，随附许可文本并提供源码获取途径：
FFmpeg 源码位于 https://ffmpeg.org/download.html。
